# One Window Conversion

## Settings

- gear when clicked it displays a list of the following and when each of these is clicked you can change the settings

-  model selection
- authentication
- System instructions
-  display (inclusive font and scaling)
-  Sound
    
## Creation Studio

- Enable Tools - Checkbox to enable tools, which adds a Tools meant to the screen
- File Menu - Menu for file operations
- Prompt menu (not present if no prompts)
- Prompt Field - Main prompt fill field (changes to Search when tools enabled)
- Tool Use Field - Additional fill field displayed when tools are enabled
- Go button
    

## Archives

- File Menu - Menu for file operations
- Archives List - List of archives, which dynamically populate using embeddings to name each archive item
    

## Viewer

- File Menu - Menu for file operations
- AI Menu - Menu for AI operations
- Viewing Area - Area for displaying text, video, and images
    

## Image Editor

- File Menu - Menu for file operations
- AI menu
- Image Workspace - Space for displaying and working on the image
- Manipulation Controls - Control to pop out the image manipulation controls
    

## Video Editor

- File Menu - Menu for file operations
- AI menu
- Video Workspace - Space for displaying and working on the video
- Playback Controls - Controls to play and rewind the video
- Timeline Control - Timeline slider for video scrubbing
- Segments Editor - Tools for splitting, deleting, and moving video segments
- Manipulation Controls - Control to pop out controls to manipulate the images
    

## Prompt Editor

- Prompts Selector - Drop-down list of prompts
- Action Controls - Controls to add, edit, save, and delete prompts
- Name Field - Name field for the prompt
- Prompt Field - Input field for prompt text
