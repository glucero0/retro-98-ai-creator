Creation Studio
Studio Mission

A general AI studio for generating text, images, and video. Write what you want in the Prompt field below. By default the Studio calls Google Gemini (paste a key in Control Panel). You can switch to OpenRouter or a local Hugging Face model anytime.

Always review generated output before relying on it — especially facts, media details, and anything you plan to publish or ship.

    Gemini

    Get a key at aistudio.google.com/apikey. Paste it below and save — it is stored in config.yaml. Studio picks the Text / Image / Video model from your prompt. Defaults are the cheapest options in each slot — customize anytime.

    Each list shows only models compatible with that modality. Refresh loads models from Google (requires a saved API key).

    OpenRouter

    Get a key at openrouter.ai/keys. Paste it below and save — it is stored in config.yaml. Studio picks the Text / Image / Video model from your prompt.

    Each list starts with a curated set. Refresh loads up to 20 popular OpenRouter models per modality (ranked by popularity). Studio picks the slot from your prompt (text / image / video).

    Hugging Face (local)

    Setup required: install local deps with pip install -r requirements-local.txt before this backend will work.

    Studio picks the Text / Image / Video model from your prompt (same slot pattern as Gemini). Text uses causal instruct models; image/video use Diffusers pipelines. Defaults are small curated Hub repos — large downloads and high VRAM use are expected.

    Each list starts with a curated set. Refresh loads up to 20 popular Hub models per modality (ranked by downloads). Save can offer a download of all three into the Hugging Face cache.
