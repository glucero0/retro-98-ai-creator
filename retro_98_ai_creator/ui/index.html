    Gemini

    Get a key at aistudio.google.com/apikey. Paste it below and save — it is stored in config.yaml. Studio picks the Text / Image / Video model from your prompt. Defaults are the cheapest options in each slot — customize anytime.

    Each list shows only models compatible with that modality. Refreshed from Google when Control Panel opens (requires a saved API key).

    Pass 1 searches and quotes sources; Pass 2 strips anything not proven by those snippets. Requires Google Search grounding. Applies to text documents only.

    OpenRouter

    Get a key at openrouter.ai/keys. Paste it below and save — it is stored in config.yaml. Google Search grounding is Gemini-only (not available through OpenRouter). Prefer routing to google/gemini-2.5-flash or google/gemini-2.5-pro for documentation quality.

    Hugging Face (local)

    Setup required: install local deps with pip install -r requirements-local.txt before this backend will work.

    Text-only in this app. Local Hugging Face loads causal instruct models for text. Image/video need Gemini (or a future Diffusers path). Pick a small instruct repo below — Hub has millions of models; you're on your own beyond this curated list / typing a known text repo id.

    Warning: small local instruct models usually cannot produce reliable game docs or keybindings. Unless you run a large local setup (e.g. 70B+ parameter models) with custom MCP (Model Context Protocol) search tools, results are often unusable compared to Gemini/OpenRouter with web search.
